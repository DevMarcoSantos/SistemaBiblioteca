# SistemaBiblioteca — Gestão de Biblioteca Universitária (TP1)

Projeto desenvolvido na trilha **Java (JDK 27)** no **IntelliJ IDEA Community Edition** como parte do Projeto de Bloco.

## Estrutura do Repositório
- `docs/`: Documento de especificação de requisitos (RF/RNF), casos de uso, diagrama UML e justificativa de escopo.
- `src/`: Código-fonte do protótipo *standalone* inicial (`Main.java`) sem orientação a objetos.

## Como Executar
1. Certifique-se de ter o **JDK 27** instalado (`java -version`).
2. Abra a pasta `SistemaBiblioteca` no IntelliJ IDEA e execute o arquivo `src/Main.java` (`Shift + F10`), ou compile e execute via terminal na raiz do projeto:
   ```bash
   javac src/Main.java
   java -cp src Main
